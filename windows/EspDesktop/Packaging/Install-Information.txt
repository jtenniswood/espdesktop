Setup changes

Setup installs EspDesktop for your Windows account and adds a Start menu shortcut. EspDesktop starts at Windows sign-in only if you enable that option in the app. You can uninstall from Settings > Apps > Installed apps. Your local settings and display pairings are kept for reinstalling.

Privacy and automatic update checks

EspDesktop stores settings and pairing credentials locally. Automatic update checks contact GitHub, which can receive your IP address, request time, and the EspDesktop Windows app identifier. On a fresh install, select "Turn off automatic update checks" on the Select Additional Tasks page to skip background checks. You can also change this in EspDesktop under Updates.

If you open the USB editor, Microsoft Edge WebView2 sends required diagnostics to Microsoft. Optional diagnostics follow Windows privacy settings. The USB editor uses Microsoft Defender SmartScreen, which may send information to Microsoft for reputation checks.
