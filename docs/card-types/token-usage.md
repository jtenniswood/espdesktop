# Token Usage

Show your weekly ChatGPT (Codex) allowance, Claude allowance, or both on a paired display. Each service shows its icon, the percentage remaining, and the time until its next reset.

1. Pair the display with the EspDesktop Mac app.
2. Open the Mac app’s **Settings** and find **Token Usage** on the connection page.
3. For ChatGPT (Codex), install the official Codex CLI, sign in with ChatGPT, and turn on sharing.
4. For Claude, install Claude Code, sign in with your Claude subscription, turn on sharing, and choose **Connect Claude Code**. Use Claude Code to get the first reading.
5. In the panel’s web editor, add **Token Usage**, select your services, and apply the layout.

Codex refreshes periodically while the Mac companion is connected. Claude refreshes when Claude Code receives usage data during normal use. The panel marks old readings **Out of date** and shows **Unavailable** until it has a weekly reading.
