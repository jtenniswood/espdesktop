# Token Usage

Show your weekly ChatGPT (Codex) or Claude allowance on a paired display. Each card shows one service with its icon, the percentage remaining, and the time until its next reset. Add a card for each service to see both.

1. Pair the display with the EspDesktop Mac app.
2. Open the Mac app’s **Settings** and find **Token Usage** on the connection page.
3. For ChatGPT (Codex), install the official Codex CLI, sign in with ChatGPT, and turn on sharing.
4. For Claude, install Claude Code, sign in with your Claude subscription, turn on sharing, and choose **Set Up Claude Code**. Open a Claude Code session and send a message to get the first reading. Claude Code shares the weekly allowance for eligible subscription sessions. API-key sessions do not include this reading.
5. In the panel’s web editor, add **Token Usage**, select a service, and apply the layout.

The Mac app shows the latest weekly percentage or the next setup step beneath each sharing toggle. Codex refreshes periodically while sharing is enabled. Claude refreshes when Claude Code receives usage data during normal use. The panel marks old readings **Out of date** and shows **Unavailable** until it has a weekly reading.
