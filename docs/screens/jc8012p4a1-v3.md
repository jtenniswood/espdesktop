# 10.1-inch Guition JC8012P4A1 V3

A 1280 × 800 touchscreen with 24 Home slots in landscape (six columns by four rows) and 18 in portrait (three columns by six rows). Cards in slots 19–24 stay saved when you rotate to portrait and reappear in landscape. [Compare displays](/getting-started/choose-a-display).

## Buy the screen

Look for the **Guition JC8012P4A1 with ESP32-P4 v3.x production silicon**. Ask the seller to confirm the chip revision before ordering. Once you have the display, verify the revision in ESPHome logs or with `esptool`. The case label and date alone can identify the wrong firmware.

- [AliExpress listing](https://s.click.aliexpress.com/e/_c4W6TYvp) for the JC8012P4A1 family. Confirm the V3 chip with the seller.
- Printable [desk stand](https://makerworld.com/en/models/2490049-guition-p4-10inch-screen-stand#profileId-2736046) and [wall mount](https://makerworld.com/en/models/2991675-wall-mount-for-10-1-inch-guition-esp32-jc8012p4a1#profileId-3357939) for the JC8012P4A1. Check the fit for your panel.

## Install test firmware over USB {#install}

Mac Companion support for this model is available in test firmware. If you already use the panel, export a backup from **System → Backup** first. USB flashing can erase the saved layout and Wi-Fi settings.

1. Open the [10.1-inch firmware PR](https://github.com/jtenniswood/espdesktop/pull/623). Under **Notes for testing**, download the latest test firmware linked there and extract `guition-esp32-p4-jc8012p4a1-v3.factory.bin`. GitHub may ask you to sign in to download the artifact.
2. Connect a data-capable USB-C cable to the P4 programming port. To enter download mode, unplug the panel, hold **BOOT** while reconnecting it, then release **BOOT** when the serial port appears.
3. Write the merged factory image to address `0x0` using [esptool](https://docs.espressif.com/projects/esptool/en/latest/esp32p4/esptool/basic-commands.html). Replace `YOUR_SERIAL_PORT` with the port for your display.
4. Restart the panel. The first boot can take up to 90 seconds to show its `EspDesktop_XXXX` Wi-Fi hotspot. Join it and open `http://192.168.4.1` to connect the display to your 2.4 GHz Wi-Fi.
5. Reconnect your computer to the same network and open the panel’s address in your browser. If you exported a backup, restore it in the web editor.

Use this command for step 3.

```bash
esptool --chip esp32p4 --port YOUR_SERIAL_PORT write-flash 0x0 guition-esp32-p4-jc8012p4a1-v3.factory.bin
```

If Wi-Fi setup repeatedly fails, see the [ESP32-C6 recovery guide](https://jtenniswood.github.io/espcontrol/getting-started/troubleshooting#a-p4-panel-has-unreliable-wifi). For later firmware updates, use native ESPHome OTA and leave the panel powered on until its first boot completes.

## Pair with your Mac

Use an **Apple silicon Mac with macOS 13 or newer**. Check [Companion compatibility](/reference/companion-compatibility) for pairing a Mac app with development firmware. Open EspDesktop on your Mac, allow local network access if prompted, then use the [setup wizard](/features/first-run) in the panel’s web editor to connect your Mac and choose up to 20 apps.

If the editor is blank or cannot save, open the panel’s address with `?espdesktop_fallback=1` at the end to use the embedded editor.
