# 10.1-inch JC8012P4A1 V3

This firmware is for JC8012P4A1 panels with **ESP32-P4 v3.x production silicon**. Confirm the chip revision from ESPHome logs or `esptool` before installing; the rear-case marking alone is not sufficient.

The V3 panel uses a 6-column by 4-row grid with 24 card slots at 1280 × 800 in landscape. At 90° and 270°, it uses a 3-column by 6-row grid with slots 1–18. Slots 19–24 stay saved and return in landscape. The web preview follows the same layout. Its firmware uses the production-silicon display initialization and the browser firmware-upload endpoint is disabled; use USB for first installation and native ESPHome OTA for later updates.

## Install

Connect the display to your computer with a USB-C data cable, then install.

## ESPHome Manual Setup

```yaml
substitutions:
  name: "kitchen-screen"
  friendly_name: "Kitchen Screen"

wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_password

packages:
  setup:
    url: https://github.com/jtenniswood/espdesktop/
    file: devices/guition-esp32-p4-jc8012p4a1-v3/packages.yaml
    refresh: 1sec
```

## Install a test build over USB

Use the factory image from a [Firmware Compile run](https://github.com/jtenniswood/espdesktop/actions/workflows/firmware-compile.yml) for this model.

1. Download the `pr-firmware-guition-esp32-p4-jc8012p4a1-v3` artifact from the run and extract `guition-esp32-p4-jc8012p4a1-v3.factory.bin`.
2. Confirm the chip is ESP32-P4 v3.x production silicon. Put the panel into download mode using its **BOOT/download** control: unplug it, hold BOOT while reconnecting the P4 USB programming cable, then release BOOT when the serial port appears.
3. Flash the downloaded **merged factory image** to the P4 serial port at address `0x0` with [esptool](https://docs.espressif.com/projects/esptool/en/latest/esp32p4/esptool/basic-commands.html), for example:

   ```bash
   esptool --chip esp32p4 --port YOUR_SERIAL_PORT write-flash 0x0 guition-esp32-p4-jc8012p4a1-v3.factory.bin
   ```

4. Reset or power-cycle the panel after the write completes. The first boot may take up to 90 seconds to create the `EspDesktop_XXXX` setup Wi-Fi network, where `XXXX` is the last four characters of the P4 MAC address.
5. Join that network and open `http://192.168.4.1` to enter Wi-Fi details, then open the panel’s web editor.

The factory image is for **USB installation**. V3 deliberately rejects browser firmware uploads with HTTP 403. Once the panel is online, use native ESPHome OTA for later updates. If the hosted editor is blank or does not save settings, use the [embedded-editor workaround](/getting-started/troubleshooting#web-configuration-changes-won-t-save) with `?espdesktop_fallback=1`.

Migrating from the V3 experimental firmware: export **System > Backup** first. USB flashing may replace the partition layout and erase stored configuration; restore the backup after Wi-Fi and the panel’s web page are working.
