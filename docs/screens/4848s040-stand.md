# Printable stand {#_3d-printable-stand-for-the-guition-4848s040}

This optional case doubles as a desk stand, angling the 4-inch touchscreen so you can see and tap it next to your keyboard. Check that your display is marked **4848S040** before printing. [See the supported display](/screens/4848s040).

## Print the case

Use the print profile and settings for your printer on the model listing. [Get the print file on MakerWorld](https://makerworld.com/en/models/2581572-guition-esp32s3-4848s040-case-stand#profileId-2847301).

![Inside the 3D-printed case, showing the mounting clips around the rim](/images/4848s040-stand-printed.jpg)

## Fit the display

1. Unplug the USB-C cable and **remove the display’s original back plate**. This gives the printed case’s mounting clips the clearance they need.

   ![Back of the Guition 4848S040 with the original back plate removed](/images/4848s040-stand-back-plate-removed.jpg)

2. Align the display with the printed case and gently press it into place until the clips engage.
3. Reconnect the USB-C cable and check that the plug seats fully and the cable has room.

If you’re setting up the display for the first time, [follow the EspDesktop installation guide](/getting-started/install).
