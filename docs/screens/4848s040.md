## Install firmware {#install}

Connect the screen with a **USB-C data cable**. In desktop Chrome or Edge, select **Install EspDesktop**.

<!--@include: ../generated/screens/4848s040-install.md-->

Select the new USB port and leave the screen plugged in until it restarts.

<p id="connect-the-display-to-wifi" class="display-setup-anchor">Join the Wi-Fi hotspot shown on the screen and open the address it lists. Select your **2.4 GHz Wi-Fi** and save, then reconnect your computer to that network.</p>

[Get help with Wi-Fi](/getting-started/troubleshooting#wifi-setup-and-reset-recovery)

## Set up the Companion app {#download}

<span id="install-a-release" class="display-setup-anchor"></span>

Use an **Apple silicon Mac with macOS 13 or newer** and install the Mac app and display firmware from the same release.

<p class="mac-app-download">
  <a class="docs-primary-action" :href="$frontmatter.macReleaseVersion ? $frontmatter.macDownloadUrl : '/download'">{{ $frontmatter.macReleaseVersion ? 'Download for Mac' : 'View Mac downloads' }}</a>
</p>

<p v-if="$frontmatter.macReleaseVersion"><a href="/download">See all Mac downloads</a></p>

<span id="pair-the-display" class="display-setup-anchor"></span>

Move EspDesktop to **Applications** and open it. Allow **Local Network** access if prompted, then select your display and choose **Continue**. Enter the eight-letter code from the touchscreen and choose **Connect**. You can also tap **Pair** on the display’s Setup screen or choose **Open pairing webpage** in the Mac app. The code stays valid until you finish pairing.

<span id="check-the-connection" class="display-setup-anchor"></span>

A green dot in the EspDesktop menu shows that your display is connected. Choose **Add device** from the same menu to pair another screen.

If the display already has a saved pairing, confirm **Reset pairing** on the touchscreen to get a new code.

When you reset pairing from the display’s web settings, the touchscreen shows a new code and the Mac shows **Pairing Required**. Select **Re-pair** in **Settings → Displays** and enter that code.

## Set up your screen {#set-up-your-screen}

After pairing, click **Configure Screen** in the Mac app. Your browser opens the display’s setup wizard, where you can choose which apps appear on your screen. To open the editor later, choose **Customize** under **Mac Settings → Displays**.

<a class="docs-primary-action" href="/features/first-run">View setup wizard</a>
