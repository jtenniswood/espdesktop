# Supported Display: 4-inch Guition 4848S040

The **Guition 4848S040** is a 4-inch square touchscreen with a 480 × 480 display and ESP32-S3 processor. It is currently the only EspDesktop display profile that supports Mac Companion controls.

Use it with the EspDesktop Mac app to launch approved apps, run shortcuts, manage windows, open folders and websites, change Mac volume, and view Mac status.

## Install

Use a USB-C data cable and [install EspDesktop firmware](/getting-started/install) from Chrome or Edge. Then [install and pair the Mac app](/getting-started/mac-app).

Mac and display firmware should be from the same release. Mac controls need both devices on the same local network.

## Hardware Notes

Some 4848S040C relay variants include three built-in relays. Relay controls are outside the Mac Companion feature set. See [Where to Buy](https://jtenniswood.github.io/espcontrol/screens/4848s040#where-to-buy) for current purchase options.
