# Supported Display: 4-inch Guition 4848S040

The **Guition 4848S040** is a 4-inch square touchscreen with a 480 × 480 display and ESP32-S3 processor. It is the display supported by public EspDesktop firmware releases.

![Guition 4848S040 touchscreen beside a keyboard on a desk](/images/4848s040-hero.jpg)

Use it with the EspDesktop Mac app to launch approved apps, run shortcuts, and open folders and websites.
