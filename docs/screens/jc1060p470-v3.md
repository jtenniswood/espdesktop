# 7-inch Guition JC1060P470 V3

A 1024 × 600 landscape touchscreen with 15 Home slots in five columns by three rows. In portrait, the grid has three columns by five rows. [Compare both sizes](/getting-started/choose-a-display).

![7-inch Guition JC1060P470 landscape touchscreen](/images/jc1060p470-hero.jpg)

## Buy the screen {#where-to-buy}

Look for a **Guition JC1060P470 with ESP32-P4 v3.1–v3.99 production silicon**. Ask the seller to confirm the chip revision before ordering. Several versions share the same model name, and a V3 chip can be in a case marked V2.

V3-specific buy links will be added here.

## Install firmware {#install}

The 7-inch V3 currently uses EspDesktop test firmware. If you already have a screen, confirm the chip revision from ESPHome logs or `esptool` before installing.

Connect the display to your computer with a USB-C data cable plugged into the port shown below. Use desktop Chrome or Edge for the browser installer.

![USB-C flashing port on the back of the JC1060P470](/images/jc1060p470-flash-port.png)

<a class="docs-primary-action" href="#esphome-manual-setup">Install manually with ESPHome</a>

Manual setup is available while the browser installer is waiting for a published V3 image. Install over USB first, then use native ESPHome OTA for subsequent updates.

If Wi-Fi setup repeatedly fails, see the [ESP32-C6 recovery guide](https://jtenniswood.github.io/espcontrol/getting-started/troubleshooting#a-p4-panel-has-unreliable-wifi) and select the V3 recovery profile.

## Connect and pair

Join the Wi-Fi hotspot shown on the screen and open the address it lists. Select your **2.4 GHz Wi-Fi**, save, then reconnect your computer to that network. Install a compatible [EspDesktop Mac app](/download). To check which app version to use with your firmware, see [Companion compatibility](/reference/companion-compatibility).

<!--@include: ../generated/screens/jc1060p470-v3-grid.md-->

With the V3 test firmware installed, open the display's network address in a browser. An empty display opens the [setup wizard](/features/first-run), where you can pair the Mac app and choose apps for the Home screen. For a display with an existing layout, **Screen → Appearance → App Subpages → Setup Again** opens the wizard. Saving from **Setup Again** replaces the Home layout.

## ESPHome Manual Setup

With ESPHome installed, save this configuration as `display.yaml`. In the same folder, create a `secrets.yaml` with your `wifi_ssid` and `wifi_password`. Connect the V3 over USB and run `esphome run display.yaml`, then select its USB port.

```yaml
substitutions:
  name: "office-screen"
  friendly_name: "Office Screen"

wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_password

packages:
  setup:
    url: https://github.com/jtenniswood/espdesktop/
    file: devices/guition-esp32-p4-jc1060p470-v3/packages.yaml
    refresh: 1sec
```

### Advanced Ethernet option

For a V3 Ethernet model, use this package with the Ethernet substitutions:

```yaml
substitutions:
  name: "office-screen"
  friendly_name: "Office Screen"
  network_transport: ethernet
  disable_updates: "true"

packages:
  setup:
    url: https://github.com/jtenniswood/espdesktop/
    file: devices/guition-esp32-p4-jc1060p470-v3/packages.yaml
    refresh: 1sec
```

This Ethernet option is for advanced manual installs only. It builds an Ethernet-only firmware: WiFi, captive portal, the WiFi setup hotspot, and Bluetooth proxy are not included, and the ESP32-C6 hosted WiFi/Bluetooth co-processor is kept off. The Ethernet build also uses the higher backlight PWM frequency used by the V2 Ethernet profile. The `disable_updates: "true"` substitution removes EspDesktop's GitHub firmware update checker and update controls, while leaving ESPHome OTA available for manual installs.

Use USB when switching a display between the WiFi and Ethernet firmware variants. OTA updates can fail during that change because the network transport changes.
