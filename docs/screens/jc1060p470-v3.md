## Install firmware {#install}

The 7-inch V3 currently uses EspDesktop test firmware. Confirm the chip revision from ESPHome logs or `esptool` before installing.

Connect a **USB-C data cable** to the [V3 programming port](/images/jc1060p470-flash-port.png). Use desktop Chrome or Edge for the browser installer.

<EspInstallButton slug="guition-esp32-p4-jc1060p470-v3" />

<a class="docs-primary-action" href="#esphome-manual-setup">Install manually with ESPHome</a>

Manual setup is available while the browser installer is waiting for a published V3 image. Install over USB first, then use native ESPHome OTA for later updates.

<p id="connect-the-display-to-wifi" class="display-setup-anchor">Join the Wi-Fi hotspot shown on the screen and open the address it lists. Select your <strong>2.4 GHz Wi-Fi</strong>, save, then reconnect your computer to that network.</p>

If Wi-Fi setup repeatedly fails, see the [ESP32-C6 recovery guide](https://jtenniswood.github.io/espcontrol/getting-started/troubleshooting#a-p4-panel-has-unreliable-wifi) and select the V3 recovery profile.

## ESPHome Manual Setup

With ESPHome installed, save this configuration as `display.yaml`. In the same folder, create a `secrets.yaml` with your `wifi_ssid` and `wifi_password`. Connect the V3 over USB and run `esphome run display.yaml`, then select its USB port.

```yaml
substitutions:
  name: "office-screen"
  friendly_name: "Office Screen"

wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_password

packages:
  setup:
    url: https://github.com/jtenniswood/espdesktop/
    file: devices/guition-esp32-p4-jc1060p470-v3/packages.yaml
    refresh: 1sec
```

### Advanced Ethernet option

For a V3 Ethernet model, use this package with the Ethernet substitutions:

```yaml
substitutions:
  name: "office-screen"
  friendly_name: "Office Screen"
  network_transport: ethernet
  disable_updates: "true"

packages:
  setup:
    url: https://github.com/jtenniswood/espdesktop/
    file: devices/guition-esp32-p4-jc1060p470-v3/packages.yaml
    refresh: 1sec
```

This Ethernet option is for advanced manual installs only. It builds an Ethernet-only firmware: WiFi, captive portal, the WiFi setup hotspot, and Bluetooth proxy are not included, and the ESP32-C6 hosted WiFi/Bluetooth co-processor is kept off. The Ethernet build also uses the higher backlight PWM frequency used by the V2 Ethernet profile. The `disable_updates: "true"` substitution removes EspDesktop's GitHub firmware update checker and update controls, while leaving ESPHome OTA available for manual installs.

Use USB when switching a display between the WiFi and Ethernet firmware variants. OTA updates can fail during that change because the network transport changes.
