# ESPHome Media Player Migration

EspDesktop now provides Mac Companion controls and local panel features. It no longer replaces a Home Assistant media-player remote. Saved media cards remain in layouts and backups as unavailable records; they do not control playback or download Home Assistant artwork.

For Mac controls, follow [Mac app setup](/getting-started/mac-app). Mac output and microphone volume remain available through [Slider cards](/card-types/sliders), and fullscreen artwork uses [Mac Companion](/features/media-cover-art).

For Home Assistant touchscreen controls, use the [EspControl documentation](https://jtenniswood.github.io/espcontrol/).
