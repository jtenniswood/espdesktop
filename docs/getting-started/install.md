# Install EspDesktop firmware {#set-up-espdesktop}

Use this browser installer for the **4-inch Guition ESP32-S3 4848S040**. Open this page in desktop **Chrome or Edge** and have a USB-C data cable and your 2.4 GHz Wi-Fi password ready. [Check the hardware and Mac requirements](/screens/4848s040#where-to-buy).

## Flash the firmware

1. Connect your display to the computer with the USB-C data cable.
2. Choose **Install EspDesktop** and select the USB port that appeared when you plugged in the display.
3. Follow the installer prompts. Keep the cable connected until the display restarts.

<!--@include: ../generated/screens/4848s040-install.md-->

If no port appears, try a cable you know carries data. If the installer reports an error, see [installer and connection troubleshooting](/getting-started/troubleshooting).

## Connect the display to Wi-Fi

1. Wait for the display to show its temporary Wi-Fi network. This can take up to 90 seconds.
2. Join the network named on the display. If the setup page does not open automatically, open the address shown on the display.
3. Select your **2.4 GHz** home Wi-Fi network, enter its password and choose **Save**.
4. When the display confirms the Wi-Fi details were saved, reconnect your computer to the home network.

The display should prompt you to download the Mac app. [Install and pair the Mac app](/getting-started/mac-app) next. If the display stays on the Wi-Fi setup screen, see [Wi-Fi setup and reset recovery](/getting-started/troubleshooting#wifi-setup-and-reset-recovery).
