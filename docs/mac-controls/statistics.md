# Show Mac Statistics

Add **Companion → Stats** cards to show readings from the paired Mac. Statistics are provided while the Mac app is connected and the display firmware supports them. A card shows `--` when a reading is unavailable.

| Statistic | What it shows |
|---|---|
| **Processor** | Current total processor use as a percentage |
| **Memory** | Used or free memory as a percentage |
| **Storage** | Used or free storage as a percentage |
| **Network** | Current combined network throughput in MB/s |
| **Battery** | Battery charge percentage; unavailable on Macs without a battery |
| **IP address** | The IPv4 address of the selected Mac network device |

For **IP address**, **Automatic (available network)** selects the first Mac network device with an IPv4 address. You can select a specific device, such as WiFi or Ethernet. Each card keeps its own choice.

Statistics use a metric icon above the reading. Memory and storage can show whether the amount is used or free; numeric cards also offer units and decimal precision. You can select **Subpage → Companion Stat** to show a statistic on a home-screen tile that opens a page of related controls.
