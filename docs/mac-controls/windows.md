# Control Mac Windows

Window cards act on the currently active Mac window. Add a **Companion → Window control** card, choose an action, and save the display configuration.

| Group | Actions | macOS version |
|---|---|---|
| **Window** | Close, Minimise, Hide App, Full Screen | macOS 13 or newer |
| **Move & Resize** | Fill Desktop, Centre, Left, Right, Top, Bottom, all four corners, Return to Previous Size | macOS 15 or newer |
| **Arrange Windows** | Left & Right, Right & Left, Top & Bottom, Bottom & Top, four side-with-quarters layouts, and Quarters | macOS 15 or newer |
| **Full Screen** | Enter Full Screen, Exit Full Screen, Left of Screen, Right of Screen | macOS 15 or newer |

EspDesktop needs Accessibility access for window controls. In the Mac app, choose **Open Settings**, then enable EspDesktop in **System Settings → Privacy & Security → Accessibility**.

Some applications or windows do not support every macOS window command. If a command is unsupported, the window stays where it is.

**Quarters** arranges four windows into equal quarters. A side-with-quarters layout arranges three windows, with one taking half the screen and two sharing the other half. **Left of Screen** and **Right of Screen** use macOS Split View; macOS may ask you to choose the second window on the Mac.

For keyboard combinations sent to the active app, see [Keyboard shortcuts](/mac-controls/shortcuts).
