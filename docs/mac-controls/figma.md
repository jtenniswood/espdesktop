# Build a Figma shortcut panel for Mac

Use the **Figma desktop app** on your paired Mac. EspDesktop can open Figma from a tile and bring up a shortcut page for the active design window.

## Create the Figma page

1. Allow Figma under **Apps** in EspDesktop on the Mac. Enable [Accessibility access](/mac-controls/shortcuts#allow-accessibility-access) for the shortcut keys.
2. In the display's web editor, choose an empty tile, add an **Applications** card, and select **Figma**.
3. In **App Subpage**, turn on **Add app subpage**. Enable **Actions**, **Frame**, **Duplicate**, **New Component**, **Collapse Layers** and **Copy PNG**. Place the ones you use most often closest to the Back tile.
4. Save the card. Choose whether the page follows Figma in [App Subpages settings](/mac-controls/apps#ready-made-app-subpages).

## Try it on a scratch design

Open a draft design in Figma. Select a layer and tap **Duplicate**. A copy should appear in the design. Select a layer and tap **Copy PNG**, then paste the result into an app that accepts images. If a tile does nothing, check that the Figma design window is active and that EspDesktop has Accessibility permission.

See [Figma in the preset reference](/reference/shortcut-presets#com-figma-desktop) for the supplied key combinations.
