# Contribute App Shortcuts

Found a useful shortcut or a preset that needs fixing? Share it so other EspDesktop users can benefit from it in the built-in **Shortcut Catalog** or on an app subpage.

## Suggest an Addition or Correction

Test the keys in the app they’re meant for, then share the app name, the action or menu item, and the key combination that worked. For a correction, name the existing preset and say what should change. For an app that’s missing, start with the actions you’d most like on the touchscreen.

[Request an app shortcut on GitHub](https://github.com/jtenniswood/espdesktop/issues/new?title=App%20shortcut%20request&body=App%20name%20and%20version%3A%0A%0AShortcut%20to%20add%20or%20improve%3A%0A-%20Action%20or%20menu%20item%3A%0A-%20Mac%20key%20combination%3A%0A-%20Suggested%20card%20label%3A%0A%0AKeyboard%20layout%20or%20settings%20required%20%28if%20applicable%29%3A%0A)

You’ll need a GitHub account. Include the app version, keyboard layout, or settings if they affect the shortcut.

## Contribute a Template

If you’d like to make the change yourself, follow the [app shortcut template guide on GitHub](https://github.com/jtenniswood/espdesktop/blob/main/product/v2/app_shortcuts/README.md). It includes an example template and steps to test and submit your changes.

For shortcuts you want to use on your own display, see [Create a Shortcut Card](/mac-controls/shortcuts#create-a-shortcut-card).
