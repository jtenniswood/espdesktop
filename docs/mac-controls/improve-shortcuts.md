# Contribute app shortcuts

Help improve the Mac app shortcuts available in the **Application** tab of a **Key Shortcut** card and on app subpages.

## Suggest an addition or correction

Use the link below to report an incorrect keyboard shortcut or suggest a missing feature you’d like to use from your EspDesktop. Include the Mac app’s name and what should be corrected or added.

For each shortcut, include the Mac key combination and a brief description of what it does. For example, in Figma, **Command + D** duplicates the selection. If you’re requesting a feature that has no shortcut, describe what you’d like to do from the touchscreen.

[Report a shortcut correction or request a feature on GitHub](https://github.com/jtenniswood/espdesktop/issues/new?title=App%20shortcut%20correction%20or%20feature%20request&body=App%20name%3A%0A%0AWhat%20should%20be%20corrected%20or%20added%3F%0A%0AFor%20each%20shortcut%2C%20include%3A%0A-%20Mac%20key%20combination%20%28if%20available%29%3A%0A-%20Brief%20description%20of%20what%20it%20does%3A%0A%0AApp%20version%2C%20keyboard%20layout%2C%20or%20settings%20%28if%20relevant%29%3A%0A)

You’ll need a GitHub account. Include the app version, keyboard layout, or settings if they affect the shortcut.

## Add a new app to the catalog {#contribute-a-template}

Send me the Mac app’s name and either a link to its keyboard shortcut reference or a list of the shortcuts you’d like to see. If you share a list, include each key combination and what it does. I can use what you share to add the app and its shortcuts to the catalog.

[Request a new app on GitHub](https://github.com/jtenniswood/espdesktop/issues/new?title=Add%20a%20Mac%20app%20to%20the%20shortcut%20catalog&body=Mac%20app%20name%3A%0A%0ALink%20to%20the%20app%E2%80%99s%20keyboard%20shortcuts%2C%20or%20list%20the%20Mac%20key%20combinations%20and%20what%20each%20one%20does%3A%0A)
