# Adjust Mac Volume

Mac volume controls use a **Slider** card rather than a Companion card.

1. Add a **Slider** card in the display setup page.
2. Set **Control** to **Mac output volume** for the selected speakers or **Mac input volume** for the selected microphone.
3. Choose a label and icons, then save the display configuration.

The slider follows volume changes made on the Mac. It is disabled when the Mac app is disconnected or when the selected audio device does not provide software volume control.
