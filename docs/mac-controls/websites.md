# Open websites on your Mac

A **Website** card opens a web address in your Mac’s default browser. Give a frequently used site, such as a calendar or project dashboard, its own tile on the touchscreen.

## Add a website card

1. Open the display’s setup page and select an empty tile.
2. Choose **Website**. If the picker shows connector tabs, look under **Companion**.
3. In the **Open URL** form, enter an `http://` or `https://` address without an embedded username or password.
4. Under **Open in**, keep **New tab** or choose **New window**, then select **Save**.

## Choose a tab or window

Use matching versions of the EspDesktop Mac app and display firmware. Safari and Google Chrome support both opening options when EspDesktop has **Automation** permission for your browser in macOS System Settings. In other browsers, **New tab** follows the browser’s usual behaviour for links opened from another app. If no browser window is open, opening a tab creates a window for it.

## Add a Web App card

Choose **Web App** under **Companion** to give a supported site, such as Google Docs, a tile with its own artwork and keyboard shortcuts. Select the site and save. Use matching Mac app and display firmware builds. When the Mac app detects the matching browser tab, the tile shows it as active. To run the Web App’s shortcuts, approve Safari or Google Chrome in EspDesktop, allow Automation for that browser, and keep the matching tab in front. For any other web address, use a **Website** card.
