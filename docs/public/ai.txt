# EspDesktop

EspDesktop pairs an ESP32 touchscreen with a native macOS app over the local network. Cards launch approved apps, open folders and websites, replay shortcuts, arrange windows and show Mac statistics. Other cards provide clocks, subpages, screen locking and direct HTTP webhooks.

Mac Companion currently supports the 4-inch 4848S040. Open Settings in the display web interface for the Companion pairing box; Screen edits the layout. Keyboard and window controls require Accessibility permission. Applications and folders must be approved on the Mac.

These docs describe the development scope in PR #55. Firmware cleanup and device validation remain incomplete. Do not describe the branch as ready to flash.
