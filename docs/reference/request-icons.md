# Request an icon

If you can’t find the icon you need in the EspDesktop card editor, you can request it for the icon picker.

1. Browse the [Pictogrammers Material Design Icons library](https://pictogrammers.com/library/mdi/) and open the icon you want.
2. Copy its exact name and page link. If you want both a filled and an outline version, include both names and links.
3. Open an icon request on GitHub. Include the icon details and a short note about where you’d use it in EspDesktop. You’ll need a GitHub account to submit it.

[Request an icon on GitHub](https://github.com/jtenniswood/espdesktop/issues/new?title=Icon%20request&body=Please%20add%20the%20following%20icon(s)%20from%20the%20Pictogrammers%20Material%20Design%20Icons%20library%3A%0A%0A-%20Icon%20name%20and%20link%3A%0A-%20Where%20I%20would%20use%20it%20in%20EspDesktop%3A%0A)
