# Frequently Asked Questions

## How Do I Find the Display's Address?

Check the physical display or your router's connected-device list. Open the address in a browser to configure the panel.

## How Do I Pair My Mac?

Open **Settings** on the display's web page. The **Mac Companion** box is first. Enter its temporary code in the Mac app. See [Mac App](/getting-started/mac-app).

## Which Cards Are Available?

Companion, Date & Time, World Clock, Subpage, Screen Lock and Webhook. See [Card Types](/card-types/).

## Which Display Supports Mac Controls?

Mac Companion currently supports the 4-inch 4848S040. Hardware installation profiles also exist for the other [listed panels](/getting-started/install); this does not imply Companion support on every profile.

## Why Is a Mac Card Unavailable?

Check pairing, the local network, approved applications and folders, and Accessibility permission for keyboard or window controls. Use matching firmware and Mac app builds.

## Can I Back Up My Layout?

Yes. Use **Export** in **Settings → Backup**. Keep backups private because they can contain webhook credentials. See [Backup](/features/backup).

## How Do I Update or Reset the Panel?

Use [Firmware Updates](/features/firmware-updates) for updates or the [Install guide](/getting-started/install) for USB installation. A normal restart does not erase the layout. A full flash erase removes stored device data.

## What If WiFi or Setup Fails?

Use a 2.4 GHz network and a USB data cable. See [Troubleshooting](/getting-started/troubleshooting) and [Collect USB Logs](/reference/collect-usb-logs).

## How Is My Data Handled?

The Mac communicates with the display locally. Updates, website resources and configured webhooks may contact external services. See [Privacy](/reference/privacy).
