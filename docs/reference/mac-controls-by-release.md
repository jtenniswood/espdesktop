# Supported EspDesktop Mac controls

The table describes the public controls in [EspDesktop v1.2.6](https://github.com/jtenniswood/espdesktop/releases/tag/v1.2.6) on the Guition 4848S040. Use the Mac app and firmware from the same release.

| Control | What it does | Setup |
| --- | --- | --- |
| Applications | Open an approved app or bring it to the front. | [Approve the app in EspDesktop](/mac-controls/apps#choose-apps-in-the-mac-app). |
| Finder folders | Open an approved folder. | [Add the folder in the Mac app](/mac-controls/folders). |
| Websites | Open a website from a touchscreen tile. | [Add the website in the display editor](/mac-controls/websites). |
| Keyboard shortcuts | Send a key combination to the active Mac app. | [Enable Accessibility for EspDesktop](/mac-controls/shortcuts#allow-accessibility-access). |
| Mac Lock | Lock the paired Mac. | [Enable Accessibility and add a Lock Machine tile](/mac-controls/security). |
| Subpages | Group controls behind a tile or show a page for the active app. | [Create a subpage in the display editor](/features/subpages). |

## Mac statistics and volume

The v1.2.6 card picker omits Mac statistics and dedicated Mac volume controls. An older layout can still contain settings for a previously saved card. If the editor marks it unavailable, [replace or remove it](/getting-started/troubleshooting#a-card-does-not-work). Keep a backup of the original layout if you plan to return to its original firmware release.

Check the [release notes](https://github.com/jtenniswood/espdesktop/releases) for controls added in a newer stable release.
