# DIY Mac touchscreen controller or Stream Deck?

Choose **EspDesktop** if you want a dedicated 4-inch touchscreen for Mac apps, folders, websites and keyboard shortcuts and are comfortable installing the firmware yourself. A physical **Stream Deck** offers tactile buttons. **Stream Deck Mobile** can use the screen on a phone or tablet you already own.

| | EspDesktop on the Guition 4848S040 | Elgato Stream Deck, 15-key model | Elgato Stream Deck Mobile |
| --- | --- | --- | --- |
| What you tap | A dedicated 4-inch touchscreen with resizable tiles | 15 physical LCD keys | On-screen keys on a supported phone or tablet |
| First setup | Flash firmware in a desktop browser, connect the screen to Wi-Fi and pair it with the Mac app | Connect the device by USB and set up keys in Elgato's desktop software | Install the mobile app and connect it to Elgato's desktop software |
| Main use | Launch approved apps and folders, open websites, send keyboard shortcuts and lock the Mac | Set up hotkeys, app actions and plugins | Use Stream Deck actions on a screen you already own |
| What to budget for | The 4848S040 display and any cable or stand you need. The Mac app is free. | The physical controller | A compatible mobile device. Check the app's free and paid options. |

The comparison uses the documented setup and capabilities for each option. Check the current system requirements and costs before buying. [Elgato Stream Deck](https://www.elgato.com/us/en/p/stream-deck) · [Elgato Stream Deck Mobile](https://www.elgato.com/us/en/s/stream-deck-mobile)

## Decide based on your desk

- **You want a dedicated display and a local Mac setup.** EspDesktop pairs on your local network. Check [which display to buy](/screens/4848s040#where-to-buy), then [set up your first app tiles](/features/first-run).
- **You need to feel the buttons without looking.** Consider a physical Stream Deck and check the plugins or actions you depend on.
- **You already have a spare tablet or phone.** Try the mobile app on that screen before buying dedicated hardware.
- **You are buying the 4848S040 for Home Assistant.** See [which EspDesktop or EspControl installer to use](/reference/espdesktop-or-espcontrol).

Check the [supported EspDesktop controls by release](/reference/mac-controls-by-release) before setting up a workflow.
