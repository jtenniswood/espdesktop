# Night Schedule

Open **Settings → Night Schedule**. Choose **Disabled** or **Time**.

In Time mode, set the daytime start and end hours, then choose the overnight action: keep the screen on, dim it, show a clock, or turn it off. Use the brightness controls for that action.

For example, daytime hours of 07:00–22:00 apply normal display behaviour during that interval and the selected night action outside it. Check [Time Settings](/features/clock) so the schedule uses the intended timezone.

Touching a sleeping panel temporarily wakes it without changing the saved hours. Configure the temporary wake brightness and idle time, after which it returns to its night action.

Enable **Show Night Mode Icon** in [Clock Bar](/features/clock-bar) to show a moon while the night period is active.
