# Speaker Groups Retired

Home Assistant speaker discovery, grouping and group-volume controls are retired. Saved speaker-group cards remain readable in layouts and backups, but no longer join speakers, change volume or open remote controls.

For Mac controls, follow [Mac app setup](/screens/4848s040#install-and-pair-the-espdesktop-mac-app).

For Home Assistant touchscreen controls, use the [EspControl documentation](https://jtenniswood.github.io/espcontrol/).
