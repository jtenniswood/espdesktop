# Clock Bar

The clock bar shows time and connectivity at the top of the panel. Configure it under **Settings → Display → Clock Bar**.

- **Show Clock Bar** turns the bar on or off.
- **Show Night Mode Icon** adds a moon while the night schedule is active.
- Select the clock or connectivity item in the web preview to hide or show it.

The monitor icon indicates a connected Mac. Tap the network status icon on the physical display to open its Settings grid, where you can see the IP address, pairing state, WiFi quality and installed build. The **Backlight** card adjusts brightness; **Back** returns to the previous page.

WiFi quality is shown on WiFi builds. Wired Ethernet uses its own connectivity indicator.
