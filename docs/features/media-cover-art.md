# Mac Now Playing Display

The display can show artwork and playback information from the paired Mac. On the 4848S040, open **Settings → Sleep & Schedule → Media Cover Art**, turn on **Show Cover Art**, and select **Mac Companion** as the source.

When macOS provides the current media session, the display can show the title, artist, album, progress, playback state, source application, and artwork. Apple Music, Spotify, and browser playback may work, depending on whether each app publishes a usable Now Playing session. Some sources do not provide every detail or artwork.

Now Playing display is a view of media reported by macOS. It does not guarantee control of every player. Mac volume and other available Companion controls are described in [Mac Cards and Capabilities](/card-types/companion).
