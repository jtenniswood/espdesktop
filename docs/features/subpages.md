# Mac Control Subpages

Subpages give related controls their own screen. Use one for an app's shortcuts, a set of folders, or a group of Mac status readings.

To create a page, select a home-screen tile, set its type to **Subpage**, and choose **Edit Subpage**. Add and arrange cards there as on the home screen. Each page includes a **Back** card, so it has one fewer available tile.

## Ready-Made App Pages

Launch cards for **Safari**, **Slack**, and **Codex** can create subpages with useful shortcuts.

1. Add a **Companion → Launch app** card and select the app.
2. Open **App subpage** in the card settings and turn on **Add app subpage**.
3. Choose the shortcuts and drag them into your preferred order.
4. Optionally enable **Auto switch to subpage**.

Safari includes Back, Forward, Reload, New Tab, and Close Tab. Slack includes Compose, Search, Direct Messages, Unread, and All Unread. Codex includes command, approval, browser, sidebar, side panel, and terminal controls.

The generated page remains editable. Turning its app subpage option off preserves your edits, so they return when you enable it again. With auto-switch enabled, the display opens the page only after the Mac confirms the app is active.

## Finder Folders

Choose **Finder** on a Launch app card and enable **Add app subpage** to create tiles for folders approved in the Mac app. Choose which folders to show and drag them into order. New approved folders can be added to enabled Finder pages when space is available.

Folder paths stay on the Mac. The display receives a friendly name and anonymous identifier. Folder highlighting may ask macOS to allow EspDesktop to control Finder.

## Companion Stat Pages

Choose **Companion Stat** as a Subpage type to show a processor, memory, storage, network, or battery reading on the home-screen tile. The page itself can contain related Mac control cards. Statistics appear while the Mac app is connected and sharing them.

For Mac card details, see [Mac Cards and Capabilities](/card-types/companion).
