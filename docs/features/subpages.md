# Subpages

A Subpage card opens another page of controls. Use it to group applications, workflows or related shortcuts.

## Set Up a Subpage

1. Add a **Subpage** card on the Screen tab.
2. Choose its label and icon.
3. Open the subpage in the editor and add cards to its empty slots.
4. Reorder and resize the cards, then apply the configuration.

Use **Back** to return to the main screen. [Idle](/features/idle) can return home automatically after inactivity.

## Mac App Subpages

Supported application cards can create an editable page of shortcuts. Enable **Add app subpage** on a Companion application card, then choose and order its shortcuts. **Auto switch to subpage** opens it after the Mac confirms the selected application is active.

A Companion Stat subpage can show a Mac reading on its parent tile. See [Mac Cards](/card-types/companion) for app and statistic options.

## Copying Cards Between Controllers

Use **Copy Code** on a card or selection, then **Paste Code** in the destination controller's editor. Review the result before applying it. Card references to Mac apps and folders must be available on the destination's paired Mac.

Use [Backup](/features/backup) when you want to transfer or preserve a full layout.
