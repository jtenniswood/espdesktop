# Time Settings

Open **Settings → Time Settings** on the display's web page.

- **Timezone**: choose **Auto (Mac)** to use the paired Mac's timezone, or choose a fixed city/timezone.
- **Clock Format**: choose 12-hour or 24-hour time.
- **Custom NTP Servers**: use reachable time servers when your network requires them.
- **Custom Month Names**: optionally supply the month labels used by date cards.

NTP supplies the clock. Automatic timezone selection uses the Mac's reported timezone, with UTC as the fallback when no usable Mac timezone is available. Check the timezone before relying on scheduled brightness or night hours.

Time is used by [Date & Time](/card-types/calendar), [World Clock](/card-types/timezones), the [clock bar](/features/clock-bar), and display schedules. Cards show a placeholder until time has synced.
