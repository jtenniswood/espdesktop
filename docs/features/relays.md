# Built-in Relays

The Guition 4848S040C relay variant includes three relays, and the ESP32-P4-86-Panel-ETH-2RO includes two relays.

Internal Switches cards are no longer supported, including in saved layouts. The standard card interface no longer exposes relay controls, and EspDesktop does not provide a Home Assistant native API.
