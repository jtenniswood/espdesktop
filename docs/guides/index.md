# What Would You Like to Control?

Start with [Install](/getting-started/install), then [connect the Mac app](/getting-started/mac-app). Configure your cards in the display's web editor.

- Use [Mac Companion cards](/#what-you-can-control) to control your Mac.
- Organize cards into [Subpages](/features/subpages), including app pages and the swipe-up page.
- Configure local [clocks](/features/clock) and [screensavers](/features/screensaver).
- [Back up your layout](/features/backup) before updates, and use [Troubleshooting](/getting-started/troubleshooting) if setup fails.

Home Assistant controls are retired. Saved configurations remain readable and unavailable cards are identified during restore. For Home Assistant panel guides, use the [EspControl documentation](https://jtenniswood.github.io/espcontrol/).
