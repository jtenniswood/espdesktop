# Top 100 Windows application shortcut audit

The audit used Chocolatey’s cumulative package download ranking as a public measure of popularity on 26 November 2026. Download counts include automated installs and updates. Windows apps distributed elsewhere may be underrepresented.
[Chocolatey Community Repository ranking](https://community.chocolatey.org/packages?sortOrder=package-download-count)

The sample follows the package order for 100 distinct desktop applications. It skips command-line-only tools, runtimes, drivers, plug-ins, retired products, and duplicate packages. For Microsoft 365 Business it lists the individual desktop apps. When a package covers a suite, the row identifies the app or shared shortcut set that was checked. The package rank column records the position of the source package before filtering.

Before the audit, **22 of 100** already had bundled presets. This change adds **69 application files**. Of these, **62** include an executable or Start menu match and **7** provide a reference guide. **9** still need Windows shortcut verification.

Display buttons require an approved foreground app. Reference guides cover browser pages, global shortcuts, and shared application hosts that lack a verified match. Menu and panel shortcuts can depend on the active view. Windows can block shortcuts to apps running as administrator.
