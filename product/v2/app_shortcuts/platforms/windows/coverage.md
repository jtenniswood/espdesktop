# Windows shortcut coverage

Each Windows JSON file lists the vendor documentation or application source used to choose its presets. The references use the vendor's default bindings for the named edition. A number of apps use different keys by edition, panel focus or keyboard layout. Microsoft Outlook, Affinity 2, Adobe Lightroom, Telegram, and Zoom have notes in their guides.

The following macOS catalogue entries needed an edition or availability check. A browser version generally shares a process with other sites. Reference-only web shortcuts require the matching tab to be in focus.

| macOS catalogue entry | Windows findings |
| --- | --- |
| Alfred | The vendor describes Alfred as a Mac app. [Alfred requirements](https://www.alfredapp.com/help/getting-started/) |
| Athena | The Windows reference uses the browser client’s explicit Ctrl bindings. [Athena shortcut source](https://github.com/jtenniswood/athena/tree/main/apps/web-desktop/src/experience) |
| Bear | Bear Web works in a Windows browser. Its web version is a separate target from the Mac bundle. [Bear Web](https://bear.app/faq/bear-web/) |
| Books | The Books app guide covers Apple devices. Windows Apple apps cover media playback and device management. [Apple Books support](https://support.apple.com/books), [Apple apps for Windows](https://support.apple.com/en-us/118290) |
| Calendar, Mail, Notes, Numbers, Pages, Photos, Reminders, Keynote | Selected apps are available on iCloud.com. The Mac catalogue targets the native Mac apps. [iCloud web feature availability](https://support.apple.com/en-us/105119) |
| ChatGPT Classic | The older macOS bundle has its own guide. The ChatGPT Desktop guide includes the current Windows app. [ChatGPT desktop app for Windows](https://learn.chatgpt.com/docs/app/windows), [original Windows app help](https://help.openai.com/en/articles/9982051-using-the-chatgpt-windows-app) |
| FaceTime | A Windows browser can join an invited call. The Mac app's shortcut set targets its native call UI. [Joining FaceTime from Windows](https://support.apple.com/en-us/109364) |
| Finder | File Explorer has its own Windows guide. EspDesktop uses its Folder controls to open approved paths. [File Explorer shortcuts](https://support.microsoft.com/en-us/accessibility/windows/keyboard-shortcuts-in-windows) |
| Final Cut Pro, Logic Pro, Pixelmator Pro | Apple lists Mac and iPad editions. [Apple Creator Studio](https://support.apple.com/en-us/125029) |
| Freeform, GarageBand, iMovie | Apple publishes its apps for Apple platforms. [Freeform](https://www.apple.com/freeform/), [GarageBand](https://www.apple.com/mac/garageband/), [iMovie](https://www.apple.com/imovie/) |
| IINA | IINA is a macOS player. [IINA downloads](https://iina.io/download/) |
| iTerm2 | The vendor publishes macOS releases. [iTerm2 downloads](https://iterm2.com/downloads.html) |
| Mail+ for Gmail | The catalogue targets the Mac App Store app. Gmail in a browser has its own keys. [Mail+ store listing](https://apps.apple.com/us/app/mail-for-gmail/id1216244845), [Gmail shortcuts](https://support.google.com/mail/answer/6594?hl=en) |
| Maps | The guide includes Apple's published browser shortcuts for Windows. [Maps on the web](https://support.apple.com/en-us/126616) |
| Messages | The catalogue targets Messages on Mac. Phone Link has its own interface for compatible phones. [Messages for Mac](https://support.apple.com/guide/messages/welcome/mac), [Microsoft Phone Link](https://www.microsoft.com/en-us/windows/sync-across-your-devices) |
| Podcasts | Apple Podcasts has a browser player. The Mac catalogue is for the installed Mac app. [Apple Podcasts on the web](https://podcasters.apple.com/support/5462-apple-podcasts-available-on-the-web) |
| Preview | The catalogue targets Apple's Mac document and image viewer. [Preview user guide](https://support.apple.com/guide/preview/welcome/mac) |
| QuickTime Player | The Mac template covers current QuickTime Player. Apple lists QuickTime 7 for Windows as unsupported. [QuickTime 7 for Windows](https://support.apple.com/en-us/106375) |
| Safari, Safari Web App | The templates target current Safari and Safari's Add to Dock web apps. Apple stopped offering Safari updates for Windows. [Apple Safari update guidance](https://support.apple.com/en-us/102665) |
| Sketch | The Windows browser can inspect, comment and share. The editor and its desktop commands require Sketch for Mac. [Sketch app requirements](https://www.sketch.com/docs/getting-started/what-is-sketch/) |
| Things 3 | Cultured Code publishes Apple platform requirements. [Things minimum requirements](https://culturedcode.com/things/support/articles/5571307/) |
| Transmit | Panic publishes Transmit as a Mac app. [Transmit 5](https://panic.com/transmit/) |
| Twitch | The preset is for a Safari web app. Twitch publishes browser-player guidance and clipping workflows. [Twitch player help](https://help.twitch.tv/s/article/playback-issue-troubleshooting), [Twitch clips](https://help.twitch.tv/s/article/how-to-use-clips) |
| Xcode | Apple's published Xcode requirements list macOS. [Xcode support](https://developer.apple.com/support/xcode/) |

Apple's Windows apps also use Alt access keys for some actions. The desktop templates include the in-app key combinations. The vendor links cover access keys and mouse gestures.
